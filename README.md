# Smart Hospital Management System (SHMS)

> A web-based platform designed to digitize and centralize core hospital operations including patient registration, appointment scheduling, doctor management, electronic medical records, and billing.

---

## 📌 Overview
Hospitals often rely heavily on manual registers, paper prescriptions, and phone-based bookings, leading to long waiting times, lost records, and scheduling conflicts. The **Smart Hospital Management System (SHMS)** addresses these challenges by consolidating administrative, medical, and booking tasks into an integrated, responsive web application.

## 🚀 Key Features

### Core MVP Features
* **Role-Based Authentication:** Secure registration and login functionality for Patients, Doctors, and Admins using JWT.
* **Patient Portal:** Registration, profile management, and personal medical history view.
* **Appointment Management:** Search doctors by department to book, reschedule, or cancel appointments.
* **Doctor Schedule & EMR:** Availability management, post-visit diagnosis, digital prescriptions, and clinical note-taking.
* **Billing & Invoicing:** Automatic simple invoice generation for completed consultations and treatments.
* **Admin Dashboard:** Centralized user management, department management, and overall system activity monitoring.

### Advanced Features (Planned)
* Email and SMS automated appointment reminders
* Online payment gateway integration (Sandbox)
* Workload, revenue, and patient inflow analytics dashboard
* Real-time bed and ward availability tracking
